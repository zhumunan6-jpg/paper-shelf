# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML, CSS and JavaScript, following the accepted GitHub Pages plan and the existing static paper reader. No server, paid API, analytics, CDN or remote fonts.

## Users

An individual reading prepared English papers on an iPhone, usually from a Home Screen web app. Desktop reading continues through the existing offline folders.

## Product Purpose

Import prepared paper ZIP packages into a local multi-paper bookshelf; retain original PDF appearance, prepared translations, contextual vocabulary, term explanations and four highlight colors. Save progress and notes on the device.

## Capabilities and Constraints

The public site contains reader code only. Papers, titles, annotations, account information and private test artifacts never enter the public repository. No ChatGPT account or cloud synchronization. An empty installation is an empty library. Backups are explicit local file exports. Incoming HTML and JavaScript are never executed.

## Brand Commitments

Concise, practical Chinese. Extend the existing reader's quiet green controls, neutral surfaces and exact paper layout. No new decorative visual identity.

## Evidence on Hand

The existing read-english-papers reader and its JSON package contract. Real papers are used only in private local testing.

## Product Principles

- Keep document content on the device.
- Read without online AI or translation services.
- Preserve original pages and exact selection lookup rules.
- Make saved data portable through local backups.
