# Reader design

Extend the existing reading interface. The bookshelf is an Operate surface and the document is a Read surface. Use Chinese system fonts for controls and the original vector pages for document typography.

Warm off-white background, white paper, dark green text and a restrained green action color. List rows rather than decorative cards. Controls have 44 px minimum touch targets, clear focus outlines, safe-area spacing, and reduced-motion support. At small widths the reader uses a compact top toolbar, a horizontally scrollable page canvas, a bottom selection toolbar and a bottom explanation sheet. The native viewport remains zoomable.

The first visit explains local import and has a single primary import action. No example paper, usage metric, account identity or personal content appears in the shipped screen. Settings explain local storage, backups, Home Screen installation and the host's standard request logging.
