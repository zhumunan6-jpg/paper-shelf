# 论文书架

一个适合 iPhone 主屏幕的本地论文阅读器。GitHub Pages 只托管通用静态代码；论文、标题、进度、高亮和批注留在设备上。

## 使用

1. 使用 Safari 打开网站，分享 → 添加到主屏幕。
2. 从桌面图标进入，再导入 read-english-papers 生成的阅读文件夹 ZIP。
3. 导入成功后可以删除手机上的原 ZIP。请在其他位置保留原始文件。
4. 设置 → 导出完整备份，可保存论文和阅读记录。清理网站数据、移除网页 App 或换设备前请先确认备份已保存。

支持原版 SVG 页面、预制翻译、上下文词义、术语解释、四色高亮、文字批注、进度恢复、搜索、离线阅读与备份恢复。长按划选，也可用“点选查译”：先点起始词，再点结束词。

## 导入格式

ZIP 可直接包含 `data/`，或包含一层外部论文文件夹。读取以下文件：

- `data/layout.json`
- `data/content.json`
- `data/pages/page-0001.svg` 等页面
- `data/original.pdf`

现有包中的 HTML、JavaScript、`work/`、`reports/` 不会执行或导入。原 PDF 的 SHA-256 必须与 layout 中记录的值一致。SVG 在本地导入时去除脚本、事件、外部链接和其他主动内容，并仅作为图片显示。完整备份使用相同 JSON 格式，并附加阅读状态。

单个 ZIP 及导入文件的解压总量上限均为 256 MiB；单个文件不超过 96 MiB；单篇不超过 500 页。大书架请按论文分别备份。重复导入保留现有标注；“导入备份”允许明确恢复并替换相同论文的阅读状态。

## 隐私边界

- 不需要账号，不采集身份，不提供远程论文或批注接口。
- 不包含示例论文、私人文件、统计、广告、远程字体、CDN 或在线模型调用。
- ZIP 在本地 Worker 中解压，JSON 以数据处理，文字以 `textContent` 显示。
- 页面 CSP 禁止连接请求、嵌入页面、对象与表单提交；离线缓存仅包含明确列出的静态应用文件。
- 公开仓库和 GitHub Pages 域名可能显示仓库所有者的 GitHub 用户名。GitHub 可能按其隐私政策记录 IP 等网站访问数据。
- 设备存储不是永久备份。Safari 与主屏幕网页 App 的本地数据也不应假定自动共享。请先添加到主屏幕，再在该入口导入和阅读。
- 备份文件含私人论文和批注，请自行妥善保管。

## 本地预览和部署

无构建依赖。可用任意静态 HTTP 服务预览，例如 `python -m http.server 8765`。生产使用 HTTPS。GitHub Pages 设置选择本仓库的 `main` 分支、根目录 `/`。

公开提交前检查：只包含应用源文件、图标和开源依赖；禁止放入论文、ZIP、PDF、测试截图、个人配置或账户凭据。`.gitignore` 是辅助措施，不能代替检查。网站可按 GitHub 当前免费政策托管，不购买自定义域名，不启用付费服务。
